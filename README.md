# open_coding

## Local Spec Search — 本地 PDF 证据检索

完整方案：[local-spec-search](local-spec-search/README.md) · [安装说明](local-spec-search/INSTALL.md)

在 VS Code 的 AI 对话中提供本仓库地址和本地 PDF 路径，让 AI 按安装说明操作。需要 Python 3.11+、Git，以及支持 MCP 的客户端。首次运行仍需确认信任本地服务。

代码可直接下载、使用和二次开发。仅代码及说明公开；用户 PDF 和索引不随仓库发布。若禁止原文上云，必须使用本地模型客户端。

当前范围：每个工作区一份带文本层的 PDF，提供页码、章节、原文证据。不承诺 OCR、多文档或通用多语言语义检索。
