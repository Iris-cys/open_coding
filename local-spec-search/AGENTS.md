# Agent instructions

When the user asks to install this project, read `INSTALL.md`, use an isolated workspace virtual environment, initialize only the PDF path explicitly supplied by the user, and run `spec-search doctor`. Never upload, commit, or copy the user's PDF or `.spec-search` index.

When changing retrieval logic, read `CONTRIBUTING.md` and `docs/VALIDATION.md`. Preserve honest evaluation labels and do not treat retrieved candidates as confirmed answers.
