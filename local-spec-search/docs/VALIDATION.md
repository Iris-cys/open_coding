## 已实现的升级

| 原问题 | 本次实现 | 验证及边界 |
|---|---|---|
| 整页关键词匹配忽略章节 | 书签及其页面坐标、文本块归属、章节辅助排序 | 提取 1599 个适用章节，7345 个块；保留术语表，排除目录 |
| FLR、Recovery 概念定位失败 | 中文术语展开与规范章节匹配 | 不内置答案页号；旧失败题现能返回正文证据 |
| 复合英文术语被拆散 | 单词检索、TF-IDF、完整短语检索融合 | 保留寄存器下划线名称的字段查询意图 |
| 上级章节反复加分 | 同一页章节加分取最大值 | 修正了初版升级的排名回退 |
| 邻页命中冒充完整证据 | 实际返回前后邻页全文；支持 read_pages 补读 | 前 3 条最多 9 页，阅读成本高于 3 个单页 |
| 标准答案缩短回退 | 完整证据短语缺失即评测报错 | 没有用前 10 词代替完整证据 |
| 固定一句话漏算等价正文 | 保留严格分数，另存 ARI 人工复核 | 事后复核不冒充盲测 |
| 每次重建索引 | 文件指纹、版本和路径检查；持久化稀疏矩阵 | 内容未变直接复用；改变后整份文档重建，不是页级增量 |
| 无关问题返回似是而非候选 | 未解析标识/低词汇覆盖时输出证据不足 | 5 道负例通过；不能证明一般无答案识别能力 |
| 脚本难以直接使用 | CLI、只读 MCP stdio、安装说明和示例配置 | 本地协议集成测试通过；尚未在用户 VS Code 实机安装 |
| p95 计算错误、样本过少 | 最近秩 p95，每题重复 5 次，排除预热 | 原始逐题结果及耗时定义随代码保存 |

后续 12 题严格未命中的两题都是 ARI。返回的第 877 页明确同时描述“256 个 Functions”以及传统的“8 个 Functions”，但原金标准只引用第 203 页的另一种措辞。原始严格成绩维持 10/12；两个等价证据的原文和实际返回检查另存 `results/ari_adjudication.json`。经这项事后人工复核，12 题都找到支持答案的原文，但该数字不能替代独立盲测。

首次留出数据原样保存在 `frozen_holdout_first_run.json`。保留不理想结果是为了能检查泛化问题和调参过程，而不是只展示最终最好成绩。

## 性能与可复现性

- 全量构建：约 33.2 秒，索引约 56.1 MiB；构建计时不含开头读取源文件计算 SHA-256 的时间。
- 导入依赖并加载已有索引：约 2.19 秒；新进程首次返回约 2.26 秒。
- 同源文件复用检查：约 186 ms，索引文件未重写。
- 持续运行进程中的查询中位耗时约 13–15 ms；各最终评测集 p95 约 23–31 ms。
- 记录中过别的单次延迟可达约 438 ms，因此不能声称每一次查询都低于 300 ms。数字来自本次共享运行环境，不含模型生成、网络、GUI，也不是用户电脑性能承诺。
- 所有结果保存源文档和题集指纹。稀疏矩阵以数值数组存入 SQLite，加载不使用 pickle。
- 集成测试验证索引复用不改写、失败重建保留旧库、返回上下文与索引原文完全一致、MCP 初始化/发现/检索/读页、非法参数及查询特殊字符。

## 尚未达到的目标

本次已完成可运行检索器、结构与短语排序、实际上下文返回、复用、准入判断、接口和评测的升级。尚不能把它验收为通用生产级知识检索系统：

1. 未完成真正多语言 embedding。运行环境缺少相关依赖；尝试访问模型配置时网络审批被取消，未获得模型文件，没有绕过限制。中文仍依赖有限词表，语义改写能力未经充分验证。
2. 广泛、独立的 Recall@3 >=95% 尚未证明。20 题开发集达到 95% 和 6 题小样本通过，不能推导任意问题都达到该水平。
3. 无答案处理是词汇/标识启发式。认识所有词但问题在文档中无答案的情况，仍可能返回候选；系统明确不自动给出确定答案。
4. 表格/图片/OCR、其他格式、4.9 GB 多文档规模未测试；本文本 PDF 的结果不外推到这些范围。
5. 5 个多段题只覆盖指定证据，不证明所有例外、脚注和交叉引用都完整。此时使用 `read_pages` 继续核对。
