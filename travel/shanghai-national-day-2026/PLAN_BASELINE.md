# 上海国庆三日行程：版本管理与事实基线

> 目的：本文件是 2026-10-01 ~ 2026-10-03 上海行程的 Single Source of Truth。后续任何排程修改必须先读取本文件；不得从旧聊天草稿恢复已被否决的安排。

## 1. 版本管理规则

1. **事实层（FACT）**：地址、营业时间、停止检票/入园时间、场次、预约时间。必须来自用户票券/预约截图或可核验来源；无法核实时标记 TBD，禁止猜测。
2. **冻结约束层（LOCKED）**：用户已经明确确认的决定。除非用户主动修改，否则后续版本不得改动。
3. **优化层（PLAN）**：只能在 FACT + LOCKED 不变的前提下优化路线、交通、餐饮与游玩时长。
4. 每次改动必须写入 Change Log。旧版本不得覆盖新约束。
5. 出现冲突时，优先级：**已预约时间 > 停止入场时间 > 用户冻结决定 > 地理聚类 > 地铁偏好 > 游玩时长优化**。
6. 交通数据若未通过地图/可靠来源核实，只能标记“待核实”，不能给出伪精确米数/分钟数。
7. **每一版对用户输出的行程都必须同步归档到 GitHub 的 versions/ 目录，不覆盖历史版本。**
8. 后续继续修改前，必须先读取本文件和最新版本文件；如果聊天上下文很长或记忆不可靠，以 GitHub 基线为准。
