GPU 学习 01：先别背 GPU 名词——为什么需要 GPU？

本课认知改变：不要从“GPU 有多少个 SM/CUDA Core”开始。先问计算机面对什么矛盾、原有 CPU 路线为何受限。架构是对目标和约束的取舍。

第一性问题

应用不断要求单位时间完成更多工作。早期的重要路线是提高处理器频率和单处理器每周期完成工作的能力。教材指出，大约从 2003 年开始，能耗与散热限制了继续依赖频率增长的路线，厂商转向在芯片中使用多个 processor cores。

更多性能需求 → 提高单核速度/频率 → 功耗与散热约束 → 不能只让一个核心更快 → 工作拆成可同时执行的 instruction sequences → 并行

认知改变：并行不是 GPU 发明的

现代 CPU 同样并行。因此“CPU=串行，GPU=并行”是错误模型。真正的问题是：两者都利用并行，为什么选择不同的硬件资源组织？

Thread 先不要背定义

先抓住教材此处更基础的表达：为了利用多个 core，应用必须能被划分成多个可以同时执行的 instruction sequences。先理解“可同时推进的执行工作”，后面再进入 thread、warp、block。

教授式口试

Q1 为什么“CPU 是串行、GPU 是并行”不准确？

现代 CPU 同样具有多核和其他并行机制；应比较硬件资源组织和优化目标。

Q2 假设无限提高 CPU 主频没有功耗散热代价，还需要多核吗？

讨论可并行工作、单线程性能、存储延迟、资源利用等，不只答是/否。

Q3 为什么增加 core 后程序不会自动获得 N 倍性能？

应用必须有可拆分的并行工作；串行部分、同步、通信和资源瓶颈都会限制收益。
